### Restatement

G a finite abelian group of order v = c·p² (p prime), φ : G → Z_p × Z_p onto, D : G → {−1, 0, 1} an SDS (v, k, λ),
s = Σ D (s² = k + λ(v − 1)), W = contraction of D along φ (|W(g)| ≤ c), Y_j the contraction along the line map ℓ_j∘φ
(ℓ_0(a, b) = b, ℓ_j(a, b) = a + (j − 1)b; fibres c·p). Claims: (i) Σ_j Y_j(ℓ_j g) = p·W(g) + s; (ii) if p ∤ s a translate of
D makes every first moment Σ_t t·Y_j(t) ≡ 0 (mod p); (iii) with t ≢ 0, 1 (mod p), p ∤ n = k − λ and t ≡ q^f (mod p) for every
prime q | n, those centred Y_j satisfy Y_j(t·h) = Y_j(h); (iv) each Y_j meets C3's demands (fibres c·p), so lies in any
complete list W of such vectors (sum s after negation, moment 0, t-fixed); if no (p + 1)-tuple from W makes every
Σ_j Y_j(ℓ_j g) − s equal p·z with |z| ≤ c, there is no SDS; (v) with p | s the same without centring and with every valid
vector listed. The rows assert `¬ HasSDS (ZMod m₁ × …) k λ` for open table entries. Unambiguous; the "|z| ≤ c" leaf is
part of the statement (C40's leaf was {0, ±p}, i.e. c = 1).

### Check 1. `fixed_lineQ` and `MultOK` against C10′: SURVIVES

- C10′ is `IsSDS.exists_translate_fixed_contract'` (`lean/SignedDifferenceSets/MultiplierWitt.lean`:549). Its hypotheses:
  φ : G → H onto, |G| = c·|H|, n = k − λ ≠ 0, |H| coprime to n; its conclusion: one translate b of the contraction is fixed
  by every t coprime to |H| with t·x = q^f·x on H for each prime q | n. Nothing more: no squarefree n (the Witt-vector proof,
  `dvd_cross`:333, handles prime powers), no self-conjugacy condition, and coprimality with |H| only, not with |G|.
  `fixed_lineQ` (`TomographyQuot.lean`:149) applies it with H = ZMod p along each line ℓ_j∘φ: |H| = p, coprimality from
  p ∤ n (`hpn`), t coprime to p from t ≢ 0, the q-condition from `hq`. It then shows b = 0 for a centred D: the translate's
  first moment M satisfies t·M = M, so M = 0 (t ≢ 1), and M = −b·s, so b = 0 (p ∤ s). I re-derived each step; correct.
  The proof only ever uses n ≠ 0 with p ∤ n, matching C41's text ("t ≢ 0, 1 mod p; t ≡ q^f for every prime q | n; p ∤ n").
- `MultOK` (`TomographyQuot.lean`:428) demands n ≠ 0, p ∤ n, t ≢ 0, 1, n = Π q^e over `fs` with each q prime (`IsPrimeTD`,
  turned into `Nat.Prime` by `.prime` inside the kernel-checked `MultOK.prime_dvd`) and t ≡ q^f. `prime_dvd` shows every
  prime divisor of n is one of the q's, so the "every prime q | n" condition cannot be dodged by an incomplete `fs`.
  `not_hasSDS_grp` (:449) passes `MultOK` or t = 1 to `fixed_lineQ`; t = 1 makes the fixed-point hypothesis trivial.
- My own check (`R47/stmts.py`, own factorization): on all 141 rows the t used lies in
  U = {t mod p : t ∈ ⟨q mod p⟩ for every prime q | n}, p ∤ n, t ≢ 0, 1; `fs` multiplies to n with q^f ≡ t. The 107 p = 7
  rows use t = 2 (U = {1, 2, 4}), the p = 13 rows t = 3, the p = 19 rows t = 4 (order 9).
- Which group is right. The explorers' U0 (`solver/src/bin/x_tomo_box.rs`:278, same in `x_tomography.rs`:262) skips every
  prime q with −1 ∈ ⟨q mod p⟩ (self-conjugate) and q = p. That is sound number theory (a self-conjugate q contributes
  q^{e/2} to (Y(ζ)) and must have even exponent or no SDS exists; the prime above p is Galois-fixed), but it is not what any
  Lean theorem here gives: C10′ needs every prime and p ∤ n; `MultiplierSelfConj.lean`'s
  `exists_translate_fixed_contract_selfConj` skips a self-conjugate q only with an even exponent (`SelfConjEven`) and still
  needs p ∤ n. The helper's stricter intersection is the right group for the Lean rows, and it is what every row uses. A kill
  in the explorers' notes that needed the wider U0 (or p | n) is exploration only until re-done with the strict group; the
  helper reports 5 p = 7 rows with p | n, which it moved to t = 1.

  set is {Σ_j w_j(0)}; when all w ∈ W share w(0) it is {(p + 1)·w(0)} ≡ {w(0)}. So the kernel check is the general
