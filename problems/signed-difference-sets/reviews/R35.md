### Statement, restated

D an SDS(v, k, λ) on an abelian group G, n = k − λ ≠ 0. Take a quotient H = C_{p^j} × K of G (p prime, p ∤ |K|,
p^i ≡ −1 on K), c = v/|H|, b with p^{2b} | n, P the order-p subgroup of C_{p^j}. Take distinct primes q not dividing
|H|, each with q^{i_q} ≡ −1 mod exp H and q^{2 j_q} | n; Q = ∏ q^{j_q}. If 2c < p^b·Q, there is no such D.
Reading: the coset sums Y(h) = Σ_{φ(g)=h} D(g) satisfy p^b | Y(h+u) − Y(h) for the generator u of P (C21's step) and
Q | Y(h) − Y(h') for all h, h' (C5 per q, combined by coprimality); |Y(h+u) − Y(h)| ≤ 2c < p^b Q, so Y is P-periodic,
and C21's last step forces n = 0. No ambiguity found in the prose; "q self-conjugate mod exp H" is read as
q^{i_q} ≡ −1 mod exp H, which is what both C5 and the Lean require.

### Finding 4 (check 1, the mathematics; SURVIVES): every step holds, each hypothesis is used

Cases and steps checked:
1. C21's step. Y = p^b X₁ + P·X₂ in ℤ[H] (Ma's lemma; C21, verified, R20) gives Y(h + u) − Y(h) = p^b (X₁(h + u) − X₁(h)),
   since P·X₂ is constant along P. Lean: `Ma.dvd_contract_sub` (`lean/SignedDifferenceSets/MaDescent.lean` l. 29), for
   every (x, kk), from the same hypotheses as `MaRule` (no bound needed).
2. C5 per q. q ∤ |H|, q^{i_q} ≡ −1 mod exp H and q^{2 j_q} | n give Y(h) ≡ Y(h′) mod q^{j_q} for all h, h′ (Turyn;
   C5, verified, R4/R10). H ≠ 1 always holds (H ⊇ ℤ_{rp}, rp ≥ 2). The self-conjugacy must hold on all of H, the
   p-part included; finding 1's control (N1181, q = 3 not self-conjugate mod 8) shows dropping that would be false.
3. Combination. Distinct primes make the q^{j_q} pairwise coprime (`natCast_prod_pow_dvd`), and q ∤ |H| with p | |H|
   gives q ≠ p, so gcd(p^b, Q) = 1 and p^b Q divides each difference along P. Repeated q would not (Nodup guard).
4. Bound. |Y(h)| ≤ c (fibres of size c, signs in {0, ±1}), so |Y(h + u) − Y(h)| ≤ 2c < p^b Q forces equality; the
   inequality must be strict (the `≤` control of finding 1 hits 8 `exists` rows).
5. Last step. Y·u = Y in ℤ[H]; in A = ℤ[H]/(Φ-type ideal killing P's sum), u ↦ ρ with 1 + ρ + … + ρ^{p−1} = 0, so
   p·ψ(Y) = 0 and p·n = ψ(Y)σ(ψ(Y))·p = 0; ℤ embeds in A (`intCast_eq_zero`), so n = 0, against k ≠ λ.
   Lean: `Ma.eq_zero_of_periodic` (`MaComb.lean`).
Small and extreme cases: b = 0 is allowed and then C29 is C5 with a composite modulus restricted to differences along
P, which is weaker than C5 and still sound; j_q = 0 contributes 1; p = 2 (N6822) is covered by C21's p = 2 case (R20).

### Finding 5 (check 2, the Lean statement; SURVIVES): `MaCombRule` says C29 and nothing stronger

`MaCombRule` (`lean/SignedDifferenceSets/MaComb.lean`) is `MaRule` (`MaRule.lean` l. 20–29) binder for binder, plus
`qs : List (ℕ × ℕ × ℕ)`, `(qs.map Prod.fst).Nodup`, per triple (q, i_q, j_q): `q.Prime`, `¬ q ∣ r * p * card K`
(= q ∤ |H|), `0 < i_q`, `∀ x : ZMod (r * p) × K, q ^ i_q • x = −x` (q^{i_q} ≡ −1 mod exp H, the p-part included),
`(q : ℤ) ^ (2 * j_q) ∣ k − lam`; and the bound `2 * c < p ^ b * ∏ q ^ j_q` in place of `2 * c < p ^ b`. With `qs = []`
it is `MaRule` (`Tests/MaComb.lean`, first example). Junk values: k − λ is taken in ℤ (no ℕ truncation); c enters
through `card G = c * card H`, not a division; in `MaCombCert.Kills` c is `ms.prod / (r p ks.prod)` in ℕ, but
`Valid` requires `r * p * ks.prod ∣ ms.prod`, so the division is exact. r is free in the statement but the
`CycloFacts` hypothesis forces r to be a power of p (R23), discharged per row by `(p, r) ∈ maPairs`. The row
theorems state `HasSDS` of `Statement.lean` on the literal group of the row (`Grp [m] = ZMod m`, `Grp [a, b] =
ZMod a × ZMod b`, reducible), with that row's k and λ.
