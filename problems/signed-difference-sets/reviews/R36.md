### Restatement

If a (v, k, λ) signed difference set D exists on G and H is a quotient of order N with c = v/N, p prime, p^(2j) | k − λ,
p ∤ N, p^i ≡ −1 on H (C5), then the coset sums a_h are all ≡ t₀ (mod q = p^j), |a_h| ≤ c, Σ a_h = ±s
(s² = k + λ(v − 1)), Σ a_h² = Q = k + λ(c − 1), and the marked counts m_h (≤ c, ≡ a_h mod 2) sum to k, so
Σ maxm(a_h) ≥ k. Hence the multiplicity vector n_x = #{h : a_h = x} over V = {x ∈ [−c, c] : x ≡ t₀ (mod q)} is a
nonnegative integer solution of Σ n_x = N, Σ n_x x = s′, Σ n_x x² = Q, Σ n_x maxm(x) ≥ k. If an exhaustive search
finds no such vector for both signs and all t₀, no SDS exists. For N27692 the claim is that the search finds none.
