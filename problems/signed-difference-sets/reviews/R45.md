### Restatement

Let p be prime, G = ZMod p × ZMod p, D : G → {−1, 0, 1} an SDS (p², k, λ) (k nonzero entries, every
nonzero shift has signed autocorrelation λ), s = Σ D, so s² = k + λ(p² − 1), and assume p ∤ s. For the p + 1
surjections ℓ_0(a,b) = b, ℓ_j(a,b) = a + (j−1)b (j = 1..p) let Y_j(t) = Σ_{ℓ_j(x) = t} D(x). Then
(i) Σ_j Y_j(ℓ_j g) = p·D(g) + s for all g; (ii) some translate of D has Σ_x D(x)·x = 0 in G, hence every
Y_j has first moment Σ_t t·Y_j(t) ≡ 0 (mod p); (iii) each Y_j meets the contraction demands (|Y| ≤ p,
Σ Y² = k + λ(p−1), every nonzero shift autocorrelation λp, Σ|Y| ≤ k with k − Σ|Y| even) and Σ Y = ±s, and
negation makes it +s; (iv) so if a finite list W contains every such vector and no choice of one W-vector
per line makes every Σ_j Y_j(ℓ_j g) − s lie in {0, ±p} (searched with sound mod-p pruning rows), there is
no SDS. (v) With n = k − λ prime and n ≢ 0, 1 (mod p), the centred Y_j satisfy Y_j(n·h) = Y_j(h).
The rows assert `¬ HasSDS (ZMod p × ZMod p) k λ` for nine open table entries. Unambiguous as stated; the
Lean leaf ({0, ±p}) is stronger than the claim's "divisible by p", which only weakens what a kill needs.

### Check 1. The mathematics: SURVIVES (one citation slip)

Every step is a Lean theorem; I re-derived each by hand and tested the statements numerically.
- Line identity. `card_lines_eq_one` (`Tomography.lean`:55) puts every z ≠ 0 on exactly one line
  ((−a/b).val + 1 for b ≠ 0, line 0 for b = 0); `sum_contract_lines` (:83) then swaps the sums:
  Σ_j Y_j(ℓ_j g) = Σ_y D(y)·#{j : ℓ_j(y − g) = 0} = p·D(g) + s. Numerically: all 110 SDS on Z_3 × Z_3
  (brute force over 3⁹ sign vectors, `R45/smallsds.py`), 0 failures.
- Centring. `exists_centered` (:145) translates by (Σ_x D(x)·x)/s, valid because p ∤ s;
  `Centered.moment_line` (:127) gives Σ_t t·Y_j(t) = Σ_x D(x) ℓ_j(x) = 0 for all p + 1 lines at once (each ℓ_j
  is linear). Numerically 0 failures on the Z_3² SDS with 3 ∤ s.
- Negation. `not_hasSDS_of_mem` (:360–375) does not assume Σ D = ±s: it derives (Σ Y_0)² = s² from line 0's
  demands, so Σ D = ±s, and `hD.neg` turns −s into +s (negation keeps k and λ). Correct.
- Certificate. `rowOf_holds` (`TomographySearch.lean`:272): if every lineSum(x) − s ≡ 0 (mod p) and w (length
  p²) has pushforwards ≡ 0 on the lines after d, then Σ_{j ≤ d} ⟨push_j w, Y_j⟩ ≡ s·Σ w (mod p), since
  Σ_x w_x·lineSum(x) = Σ_j ⟨push_j w, Y_j⟩. For an SDS, lineSum − s = p·D, so every row holds. Any vanishing
  w gives a valid necessary condition, so a bad choice of certificate can only weaken the pruning, never make
  it unsound; `certOK` checks the vanishing, `tomoGo_sound` (:153) and `no_choice` (:338) close the argument.
  The leaf (`unitStep`, {0, ±p}) is stronger than the claim's "divisible by p": the kills need less than stated.
- `fixed_line` (`TomographyOrbit.lean`:109). It applies `IsSDS.exists_translate_fixed_contract`
  (`Multiplier.lean`:496) to H = ZMod p, c = p: its hypotheses are k − λ squarefree (n prime), p and n
  coprime (n ≢ 0), t = n coprime to p, and for every prime q | n some f with t·x = q^f·x (q = n, f = 1).
  The translate b is then 0: the translate's first moment M satisfies n·M = M, so M = 0 (n ≢ 1), and
  M = −b·s, so b = 0 (p ∤ s). Correct.

  every p = 11 row's doc ("a multiplier (C10)") cite C10, but the theorem used is C16's
