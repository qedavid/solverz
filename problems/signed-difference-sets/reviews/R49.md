### Restatement
D an SDS (v, k, lambda) on G, s = sum D, phi : G -> Z_p^r onto (fibres c = v/p^r). For a list of N hyperplane maps h_m
whose kernels cover every point of Z_p^r either N times or exactly alpha < N times, sum_m y_m(h_m q) = alpha s +
(N - alpha) Z(q), with y_m the contraction of D along h_m o phi (fibres C = v/p) and Z(q) the sum of D over
phi^-1(q + K), K the common kernel, |Z| <= c|K|. All hyperplanes: p^(r-1) W(q) = sum_f y_f(f q) - ((p^(r-1)-1)/(p-1)) s.
Each y_f meets C3's demands; when p does not divide s a translate makes every y_f's first moment 0 mod p; when it does,
a translate puts each of the r coordinate hyperplanes' largest |y| at 0. If no choice of listed vectors makes every
checked flat value alpha s + (N - alpha) z with |z| <= c kappa (and, at the leaf, sum |W| <= k where used), there is no
SDS. Rows: "no SDS (v, k, lambda) in G" for 41 built rows (+ N758 unbuilt). No ambiguity found in the statement; the
one loose sentence is Finding 2.
