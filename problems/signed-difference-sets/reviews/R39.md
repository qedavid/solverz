### Restatement

An SDS D on a finite abelian group G with n = k − λ > 0 and a surjection G → ZMod m with fibres of size c gives coset sums
f : ZMod m → ℤ, |f| ≤ c, with autocorrelation n·[g = 0] + λc. Take an odd prime p with p² ∣ m, F = m/p, t = 1 + F (a unit
of order p mod m). If, for every prime q ∣ n, t lies in the cyclic subgroup ⟨q⟩ of the units modulo the q-free part of m,
then φ(m)·n ≤ m·F·c². A row (v, k, λ, G) is killed when some cyclic quotient m of G and some such p give
m·F·(v/m)² < φ(m)·n.

Read literally (`lean/SignedDifferenceSets/FieldDescent.lean`, lines 636–680):
- `ordCompl[q] m` = m / q^(v_q m), the q-free part of m: the decomposition group of the primes over q in

  "σ_t lies in the decomposition group of every prime over n". In the primed form, ∃ a with q^a ∣ m and the congruence
  mod m/q^a: m/q^a is a multiple of m_q, so this is equivalent (a = v_q(m) is the weakest choice); nothing is lost.

- Fibres: `Fintype.card G = c * m` with φ onto, so each fibre has c elements; the conclusion is in ℤ with m/p exact.
- No junk: m > 1 and `NeZero m` given; ℕ division only in m/p and m/q^a, both exact; `(k : ℤ) − lam` in ℤ.

### Check 2: the proof's mathematics: SURVIVES

Each step re-derived by hand against the Lean (`FieldDescent.lean`):
- S1, ramified q (`smul_eq_self_of_pow`, lines 49–87): m = q^a·m'' (any a with q^a ∣ m, m'' may still contain q).
  In 𝓞K/P (characteristic q) y = ζ mod P has (y^m'')^(q^a) = 1, and Frobenius is injective, so y^m'' = 1; with
  t ≡ q^e (mod m''), σ_t and Frob^e agree on ζ, hence on 𝓞K = ℤ[ζ]; so σ_t(P) ⊆ P and P maximal gives equality. Valid
  whether q ∣ m or not; no unramified assumption is used.
- S2 (`associated_of_forall_smul`): X ∣ n and σX ∣ n; at P ∌ n both valuations are 0; at P ∋ n, v_P(σX) = v_{σ⁻¹P}(X) =
  v_P(X). Equal ideal factorizations in the Dedekind domain 𝓞K give associates. S3/S4: |φ(X)|² = |φ(σX)|² = n at every
  embedding (`norm_sq_elt`, from `chi_mul_conj_eq` at units b ≠ 0), so the unit is a root of unity (Kronecker), ±ζ^k.
- η^p = 1 (`exists_smul_fixed`, lines 418–436): t = 1 + F with m ∣ F² gives t^l = 1 + lF, t^p = 1 + pF ≡ 1, and
  Σ_{l<p} t^l = p + F·p(p−1)/2 = p + m(p−1)/2 ≡ p (mod m) because p is odd. X = σ^p X = (∏_{l<p} σ^l η)·X and
  ∏ σ^l(ε ζ^κ) = ε^p ζ^{κ Σ t^l} = (ε ζ^κ)^p = η^p (ε = ±1 is σ-fixed), so η^p = 1; η = ζ^{Fs}; then
  σ(ζ^{−s}X) = ζ^{−s(1+F)}ζ^{Fs}X = ζ^{−s}X. For p = 2 the sum is 2 + m/2 ≢ 2 and the step fails; p odd is required
  and assumed.
- Bound (`chi_eq_chi_restrict_of_chi`, `totient_mul_le_of_chi`): ρ∘σ^u sends ζ to ψ(a(1 + Fu)), so σ^u-invariance of
  W = ζ^{−s}X gives χ_{a(1+Fu)}(f_s) = χ_a(f_s) for every unit a and u < p; averaging, Σ_{u<p} ψ(aFh)^u = p·[Fh = 0]
  (ψ(aFh) is a p-th root of unity since p·aFh = a·m·h = 0, and ≠ 1 unless Fh = 0 as a is a unit), so χ_a(f_s) = χ_a(f_s·1_{Fh=0});
  |{h : Fh = 0}| = F; Parseval: φ(m)·n = Σ_{a unit} |χ_a(g)|² ≤ Σ_a |χ_a(g)|² = m·Σ g² ≤ m·F·c².
- Numerically (`R39/objects_check.py`): on the 9 (known set, m, p) triples meeting the hypotheses,
  some translate f_s satisfies χ_{at}(f_s) = χ_a(f_s) for every unit a, and χ_a(f_s) = χ_a(restriction to Fh = 0): the
  intermediate claims hold on real data. Of the 10 triples where the q-condition fails, 6 have no such translate
  (e.g. O39, SDS(300, 55, 6), m = 75, p = 5), so the descent genuinely uses the hypothesis.
- Schmidt: Tan's survey (arXiv:1610.01914v4, Def. 2.10, Results 2.11–2.12, attributed to Schmidt, Characters and
  Cyclotomic Fields in Finite Geometry, LNM 1797, Thm 2.2.8) defines F(v, n) via b(r, v, n) = max over q ≠ r of
  ν_r(q^{r−1} − 1) + ν_r(ord_{μ_q} q). `R39/ls_equiv.py`: for odd p, p² ∣ m, the M1 q-condition equals
  "v_p(m) > ν_p(q^{p−1} − 1) + ν_p(ord_{μ_q} q)", i.e. Schmidt's exponent allows dropping one power of p; 14,784
  (m ≤ 1000, p, q < 400) triples agree, 0 disagree. `R39/subset_tan.py`: all 3,335 (row, m, p) kills of
  M1 in the table have F(m, n) ∣ m/p and are kills of Tan's F-bound n ≤ c²F²/φ(F) on the same quotient. M1's bound
  φ(m)n ≤ m(m/p)c² is that F-bound at F = m/p (m/φ(m) = F/φ(F) when p ∣ F). So M1 is a special case of Schmidt's
  published field descent, with the same proof idea.
