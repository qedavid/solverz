### Restatement

D : G -> {0, ±1} on a finite abelian group G of order v, k nonzero entries, Σ_x D(x)D(x+g) = λ at every g ≠ 0,
n = k − λ, s = Σ D (so s² = k + λ(v − 1)). Take a surjection φ : G -> H = Z_{rp} × K with p an odd prime,
r = p^(j−1), p^i h = −h on K (so p ∤ |K|), p^e | n, 1 ≤ b ≤ e/2; c = v/|H|. Reduce further along
H -> H' = Z_r × K (fibres p), so χ : G -> H' has fibres pc, and let W(y) = Σ_{χ(x)=y} D(x). Claim: p | W(y) for every
y, and Z = W/p satisfies |Z| ≤ c; Σ Z² = Q with p²Q = k + λ(pc − 1); Σ_y Z(y)Z(y+g) = t with pt = λc for g ≠ 0;
Σ Z = ±s' with p s' = s; Σ|Z| ≤ k' for any k' ≡ k (mod 2) with k < p(k' + 2). So if no integer vector on H'
meets these demands, no SDS exists.
Ambiguity: the prose omits that Σ|Z| ≡ k' (mod 2) is also demanded (the Lean `DemandsQ.parity`, and the search's
`(k − abs) % 2 = 0`); it follows from the hypotheses (shown below), so the most natural reading and the Lean agree.

### Check 1: the mathematics (SURVIVES)

Derivation redone by hand. Let χ = ψ∘φ : G -> H' (fibres pc, kernel of order pc) and W = χ(D) in Z[H'].
- p | W(y): C33's step (Ma's lemma on H = Z_{rp} × K: the Sylow p-subgroup of H is Z_{rp}, cyclic, since p^i + 1
  kills K so p ∤ |K|; Turyn's self-conjugacy gives χ(Y) ≡ 0 mod p^b for characters nontrivial on P = <(r, 0)>, so
  Y = p^b X1 + P X2 and Y(h + u) ≡ Y(h) mod p^b; each W(y) adds p values of Y along a P-coset, ≡ p·Y(h) ≡ 0 mod p).
  Reviewed for C33 in R40; Lean `Ma.dvd_contract_quot` (`MaDivided.lean:152`) iterates `Ma.dvd_contract_sub`.
- |Z| ≤ c: |W(y)| ≤ pc (fibre size). ✓
- Σ W² = Σ_{g ∈ ker χ} Σ_x D(x)D(x+g) = k + λ(pc − 1), so p²Q = k + λ(pc − 1). ✓
- g ≠ 0 in H': Σ_y W(y)W(y+g) = Σ_{g' ∈ χ⁻¹(g)} λ = λpc, so p²t = λpc, pt = λc. ✓
- Σ W = Σ D = s, s² = Σ_g Σ_x D(x)D(x+g) = k + λ(v − 1); Σ Z = s/p (the Lean derives (ΣZ)² = s'² from
  ΣW² + (|H'| − 1)λpc = k + λ(v − 1), `MaDivided.lean:295-310`). ✓
- Σ|W| ≤ Σ_y #{x in fibre y : D(x) ≠ 0} = k, and |W(y)| ≡ that count (mod 2) (each ±1 is odd), so Σ|W| ≡ k (mod 2).
  With A = Σ|Z|: pA ≤ k and, p odd, A ≡ pA ≡ k ≡ k' (mod 2). From k < p(k' + 2): A < k' + 2, so A ≤ k' + 1, and
  parity gives A ≤ k'. ✓ (For p = 2 the parity step fails, as C34 says; N20961 is rightly left out.)
- Sign: `false_of_noVectorQ'` reduces ΣZ = −s' to ΣZ = s' by negation and puts a largest |Z| at 0 by translation;

  the generator's k' = ⌊k/p⌋ or ⌊k/p⌋ − 1 (parity) meets it.

## Literature

Opened (2026-11-10):
- He, Wu, "Nonexistence results and constructions for signed difference sets", arXiv:2608.22936 (abstract page: v1
  2026-08-24, v2 2026-09-20; HTML v2): obstructions Thm 3.2 (self-conjugate prime ⇒ v_p(n) even), Thm 4.2 (v even ⇒ n a
  square), Thm 4.4 / Cor 4.5 (k = v − 1), Thm 4.7 (C_p^m, small defect); their "support-refined quotient method" compares
  coefficients in Z[G/H]; no Ma's lemma, no division of a contraction by p, no integer-vector search. None applies to
  the 27 rows (all have n = 25, 36 or 81, a square with v_p(n) even; k ≠ v − 1; no group is elementary abelian).
- Gordon, "Signed difference sets", arXiv:2212.10630 (ar5iv): contraction intersection numbers (Lemma 5.2:
  Σ b_h = s, Σ b_h² = k + λ(d − 1)) used to organise existence searches; no Turyn/Ma divisibility, no division by p.
- Arasu, Gordon, Zhang, "New nonexistence results on circulant weighing matrices", arXiv:1908.08447 (v3 2021-05-11;
  ar5iv): the closest relative — CWs folded to a quotient (ICW), Lemma 1 (sum s, square sum k, |b_i| ≤ d), Theorem 2.1
  (Lander/Jungnickel: AA^(−1) ≡ 0 mod p^(2a), p self-conjugate ⇒ A ≡ 0 mod p^a) to make the intersection numbers
  trivial mod p^a, then the sum equations solved by hand or a short search; orbit-wise exhaustive search in Section 5.
  So "contract, use self-conjugacy divisibility, then solve the integer sum/square-sum system" is published for circulant
  weighing matrices; C34 differs in using Ma's lemma at the edge of a quotient with p | |H'| (where Theorem 2.1 alone
  does not give divisibility) and in applying it to SDSs.
- R40 (opened there, not re-opened): Feng–Leung–Schmidt–Smith 2013, the same G/P divisibility step for ordinary
  Hadamard difference sets.
