### F2. Objects: all 16 sets are SDSs with their parameters (SURVIVES)

- Independent check `R34/check_objects.py` (log `check_objects.log`), sharing no code with the solver
  or the Lean files: it parses `objects/O<n>.txt` into a sign array on ℤ_{m₁} × ⋯ × ℤ_{m_r} (the row's coordinates),
  and checks (a) exactly k nonzero entries; (b) Σₓ D(x)D(x+g) = λ for every one of the v − 1 nonzero shifts g, by
  translating the whole array (`np.roll` along every axis); (c) by characters (n-dimensional FFT):
  |D̂(χ)|² = k − λ for all χ ≠ 1 and D̂(1)² = k + λ(v − 1); (d) negative controls: one randomly chosen element's sign
  flipped, and one element dropped (tested against k and k − 1), must fail both (b) and (c); (e) the Lean file's
  `plus`/`minus` masks decode (mixed radix, first factor most significant, as `Indexed` in
  `lean/SignedDifferenceSets/Index.lean`) to exactly the object file's set, with disjoint masks; (f) the header's
  group and (v, k, λ) equal the row key and the Lean theorem.
- Result: all 16 pass (a)–(f); every control is rejected. Signs (+/−): O61 4/14, O62 18/8, O63 82/30, O64 110/11,
  O65 12/165, O66 82/117, O67 190/57, O103 50/32, O79 25/13, O80 11/35, O81 46/22, O82 29/11, O83 29/11, O84 29/11,
  O101 25/13, O104 39/9.
- Checker validation (`validate_checker.py`, log `validate_checker.log`): on Gordon's stored sets (status Yes/All,
  v ≤ 120, first set; his primary-decomposition coordinates) 55 of 62 pass both (b) and (c). The 7 failures, all
  cyclic "All / Orbit Exhaust" entries (20,11,2), (35,21,10), (51,19,3), (61,49,36), (78,53,28), (104,29,4),
  (111,66,17), also fail a plain-Python autocorrelation (off-peak values e.g. {−2, 0, 2, 4} for (20,11,2)): these
  stored sets are not SDSs as stored. R16 (`reviews/R16.md`) already reported this for (20,11,2), (51,19,3),
  (104,29,4); the other four are not in R16 (a side note for the database corrections; none is a P4 target).

### F3. Credit, I21 (O79–O84, O101, O104): the doubling is a published weighing-matrix construction; "us" must cite it (FLAWED credit, sets still new)

- Structure confirmed (`R34/doubling.py`): each of the 8 sets has exactly one involution u with
  |D(y)| = |D(y + u)| for all y, and D = (1 + u)Z + (1 − u)T with Z the halved SDS (|Z| = (k + λ)/4: 10, 14, 18, 11,
  11, 11, 10, 15) and T of weight n/4 (9, 9, 16, 9, 9, 9, 9, 9), checked by characters (χ(u) = 1: |χ(D)|² = n from Z
  alone; χ(u) = −1: from T alone). That covers the twisted ones too (O82, O104: u = (0, 12) in ℤ₃ × ℤ₂₄).
- Prior art (opened): Arasu, Kotsireas, Koukouvinos, Seberry, "On circulant and two-circulant weighing matrices",
  Australas. J. Combin. 48 (2010) 43–51 (PDF read via `pdftotext`, `R34/papers/akks2010.txt`):
  Thm 4: if ε is a central involution of G, B is a W(G, k), C has coefficients 0, ±1 with ρ(C) a W(G/⟨ε⟩, k), and
  B, εB, C, εC are pairwise disjoint, then A = (1 − ε)B + (1 + ε)C is a W(G, 4k). The paper sends the reader to
  Arasu, Leung, Ma, Nabavi, Ray-Chaudhuri, "Circulant weighing matrices of weight 2^{2t}", Des. Codes Cryptogr. 41
  (2006) 111–123, Thm 2.3 (paywalled, not opened), and states the cyclic forms: Thm 5 (two disjoint CW(n, k), n odd
  → CW(2n, 4k)), Thm 6 ([[A+B, A−B], [A−B, A+B]] is a W(2n, 4k)) and Thm 3, Arasu–Dillon's CW(n, k), n odd →
  CW(2ᵗn, 4k), t > 1 (Perfect ternary arrays, NATO ASI C 542, 1999; not opened). Aragón Artacho, Campoy,
  Kotsireas, Tam, arXiv:1711.02502 (HTML opened) Thm 4.2 restates it for CW(n, k²) pairs, "a consequence of
  [ALMNR, Thm 2.3]".
- I21's D = P·Z + (1 − u)·T (P = 1 + u) is that construction with C = Z, B = T, except that Z may have λ/2 ≠ 0
  (ZZ* = n/4 + (λ/2)K), which passes through because (1 + u)(1 − u) = 0 and (1 + u)K = G; at λ = 0 it is exactly
  AKKS Thm 4. The twisted form (TT* = n/4 only modulo 1 + u, i.e. in ℤ[x]/(xʳ + 1) ⊗ ℤ[K]) needs only
  (1 − u)TT* = (n/4)(1 − u), a mild weakening of AKKS's "B is a W(G, k)", and is the same 2-adic splitting
  Arasu–Dillon's CW(2ᵗn, 4k) uses.
- So `ideas/I21.md` ("Source. us (from C26)") and `objects/_objects.md` rows O79–O84, O101, O104 (Source "us") omit
  the precedent. Correct credit: "doubling of Arasu–Leung–Ma–Nabavi–Ray-Chaudhuri (2006, Thm 2.3) / Arasu–
  Kotsireas–Koukouvinos–Seberry (2010, Thm 4), stated there for weighing matrices (λ = 0); its extension to SDSs
  with λ ≠ 0, the twisted T, and the eight sets are ours". No SDS paper has it: Gordon (arXiv:2212.10630, local
  text: Props 2.1–2.3, Thm 3.2, Thm 4.1, Thm 6.1 only), He–Chen–Ge (arXiv:2306.05631 v1, the only arXiv
  version; local text: §3 PDS, §4 product in 3-groups, §5 order-4 cyclotomy), He–Wu (arXiv:2608.22936v2 HTML:
  Thm 5.3 PCP spreads in C₂^{2m}, Thm 5.6 (125, 28, 3); no product or doubling). The rows stay new results.
- Side note: O104's ingredient Z, a (36, 15, 6) Menon–Hadamard difference set in C₄ × C₃², is described as "found
  by annealing"; such sets are classical objects, so the credit line should not suggest Z is new (I did not open a
  source for C₄ × C₃² specifically).

  (index 3, not a direct factor), x₀ = (0, 0, 0, 1) of order 9; the x₀-coset part is x₀ + {(0, b, c, 0)} (9

- He–Chen–Ge Thm 4.1 (arXiv:2306.05631 v1, lines 273–331 of the refuter's local text, not redistributed) is stated
  only for G = (F_{3^{2m+1}}, +) = G₀ × G₁ × G₁, so it does not cover C₃³ × C₉. Its proof transfers verbatim: for χ

### F5. Credit, I19 X1 and X3 (O61–O67): not found published; "ours, in known frameworks" stands (SURVIVES)

- X1 (O64–O67, GF(3⁵) and GF(7³)): signed unions of ⟨gᵉ, φ⟩-orbits of cyclotomic classes, e = 22, 22, 38, 18.
  Character values (`R34/charvals.py`) show the Paley component: O64 takes −½ − r ± i√243/2,
  r ∈ {4, −5}; O65 takes −4.5 ± i√243/2 and 9; O66 takes −10.5 ± i√343/2 and 14; O67 has 9 values.
  O64 in closed form (`structure.py`): D = Q − B as group-ring elements, Q = P ∪ (−N) the nonzero squares of
  GF(243) (a skew Hadamard difference set: Q ∪ −Q = G \ {0}, |χ(Q)|² = 61) and B = N ∪ (−N) = ⟨g¹¹⟩, the
  Berlekamp–van Lint–Seidel PDS (243, 22, 1, 2) (χ(B) ∈ {4, −5}). This is an instance of a general identity: a skew
  Hadamard difference set Q minus any symmetric PDS B ∌ 0 with λ_B − μ_B = −1 is an SDS with k = (v − 1)/2,
  n = (v + (r − s)²)/4, since χ(D) = −½ − r ± i√v/2 and r + s = −1. I found no source for this identity or for
  any of the four sets; He–Chen–Ge's cyclotomic constructions (§5, Props 5.3–5.5) need q ≡ 1 (mod 4) and order-4
  classes, while 243 ≡ 343 ≡ 3 (mod 4). The ideator's credit line ("ours, citing He–Chen–Ge's cyclotomic
  framework") stands; a proposal should add Paley and Berlekamp–van Lint–Seidel as O64's ingredients.
- X3 (O61 (42, 18, 2) in ℤ₄₂, O62 (75, 26, 1) in ℤ₅ × ℤ₁₅, O63 (217, 112, 12) in ℤ₂₁₇): orbits of a diagonal
  subgroup of Π GF(q_t)^*, i.e. generalized cyclotomic classes (Whiteman 1962, Ding–Helleseth 1998, not opened
  here), the shape of Gordon's Thm 4.1 (opened, local text: (4n − 9, 2n − 1, n − 1) in GF(q) ⊕ GF(q + 6), which
  gives none of these: 75 ≠ q(q + 6) for a 3, 25 pair, 217 = 7·31, 42 is even). The cyclic ones are ternary
  sequences with two-level periodic autocorrelation (He–Chen–Ge §2 makes the link); a search of that literature
  found none of period 42 or 217 (Hu–Gong ISIT 2010, cited by Gordon, concerns period 2ⁿ − 1).
- Searches (2026-11-09) that found nothing beyond Gordon, He–Chen–Ge, He–Wu: "signed difference sets" new
  constructions 2025/2026; the parameter triples (42,18,2), (217,112,12), (75,26,1) with "signed difference set" or
  "ternary sequence"; ternary two-level autocorrelation from generalized cyclotomy of period pq; skew Hadamard
  difference set minus a partial difference set as a signed/ternary set; "signed difference set" with doubling or a
  C₂ factor. Gordon's publication page (dmgordo.org/publications, opened) lists no SDS work after the 2023 paper;
  his arXiv:2501.14924 (abs opened) is on cyclic relative difference sets and CW matrices (λ = 0).
