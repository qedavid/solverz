# I25 The mod-q split on quotients: deciding the quotients E8 cut (none)

For a prime q ∣ n with q ∤ v, every quotient H of G is prime to q, and a vector Y on H meeting C3's demands has
Y·Y^(−1) = n + λcH in ℤ[H], so ψ(Y)ψ(Y^(−1)) ≡ 0 mod q for every nontrivial ψ : H → F̄_q^× (C24 on H). Per branch (one class of each
inverse pair, all self-inverse classes) Y mod q lies in an affine subspace; with q > 2c the pivots pin Y outright. This adds no
constraint beyond C3 but makes the quotient search finish: on N20961's C₂₀, E8 is cut at 5·10¹⁰ nodes, the split decides it in
2.4·10⁶. A quotient with no C3 vector kills the row.
