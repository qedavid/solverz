# I17 Mod-q split of the orbit search (none, and finds sets)

For gcd(v, n) = 1, a translate of D is fixed by the multiplier group M (C15, I13). For an odd prime q | n, C24 splits
each inverse pair {C, −C} of q-cyclotomic classes of characters: D vanishes on one of them (and on every self-inverse
class). On M-fixed D each vanishing class is F_q-linear in the orbit values; in each branch the orbit vector lies in a
subspace of about half the dimension, and −1, 0, 1 are distinct mod q, so the search enumerates the free coordinates
and reads the rest off mod q (about 3^(r/2) · 2^pairs leaves instead of 3^r).

Rows: the 412 rows with gcd(v, n) = 1 and ≤ 50 M-orbits (core class B1, main folder
`scratch/ideator/none/core_class.tsv`), 278 cyclic. Prototype: NONE on N592, N822, N3474, N7872, N49202, N49235.

**Lean design (cyclic G = ZMod v).** Per row: f ∈ F_q[y] with f | y^v − 1 and f | Σ_{x<v} y^x (polynomial division in
the kernel); Q = F_q[y]/(f), K = Q/m for a maximal ideal m (no irreducibility proof needed); ψ(x) = y^x. Per branch, a
matrix L over Q with L · A = [I | −R] (A: the vanishing classes' rows ψ_j(O_i)), so the pivot orbit values equal R ·
(free values) in ZMod q; the leaves run over the free values in {−1, 0, 1} and test |D| = k, ΣD = ±s and the orbit
autocorrelation (as `OrbitSearch`). One theorem: C24 + that check ⇒ ¬ HasSDS; one `decide +kernel` per branch slice.
**Technique.** `T438` Multiplier theorems and character sums for nonexistence; — duadic splitting mod q.
