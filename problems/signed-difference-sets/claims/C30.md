# C30 Signed combinations of a relative difference set (I15's families)

Let R be a relative difference set relative to N in G, |N| = n.
1. R semiregular, (n², n, n², n), R ∩ N = {0}: R − N is an SDS (n³, n² + n − 2, n − 2), and G − R − N is an SDS
   (n³, n³ − n² − n + 2, n³ − 2n² − n + 2).
2. R affine, (q + 1, n, q, (q − 1)/n), R ∩ N = ∅, v = n(q + 1):
   (a) G − 2R − N is an SDS (v, nq, q(n − 4)) if q = (n/2 − 1)²;
   (b) G − R − 2N is an SDS (v, v − q, v − 2q) if q = (2n − 1)².
(Each combination takes values in {0, ±1}: e.g. G − R − N is +1 off R ∪ N, 0 on (R ∪ N) ∖ {0}, −1 at 0.)

**Proof.** With ρ = RR^(−1), GX = (ΣX)G, NN^(−1) = nN, NR^(−1) = (RN)^(−1).
(1) RN = G and ρ = n² + n(G − N), so (R − N)(R − N)^(−1) = ρ − 2G + nN = n² + (n − 2)G, and
(G − R − N)(G − R − N)^(−1) = (n³ − 2n² − 2n)G + ρ + 2G + nN = n² + (n³ − 2n² − n + 2)G.
(2) RN = G − N and ρ = q + λ_R(G − N), λ_R = (q − 1)/n; then
(G − 2R − N)(·)^(−1) = 4q + (v − 4q − 2n + 4λ_R + 4)G + (n − 4λ_R − 4)N,
(G − R − 2N)(·)^(−1) = q + (v − 2q − 4n + λ_R + 4)G + (4n − λ_R − 4)N;
the coefficient of N vanishes exactly when λ_R = n/4 − 1, i.e. q = (n/2 − 1)², resp. λ_R = 4n − 4, i.e. q = (2n − 1)².
