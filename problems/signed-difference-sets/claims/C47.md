# C47 The mod-q split with exact relations (I17's NONE rows)

Let D be an SDS (v, k, λ) on ZMod v with gcd(v, n) = 1 and a C9 multiplier t; E a t-fixed translate with orbit vector b. For a prime
q ∣ n and each pair of character classes with monic f over F_q whose orbit periods Σ_{lab y = c} X^y mod f are constants ρ_c, C24
(`IsSDS.charSum_eq_zero_or`) at a root ζ of f gives q ∣ ρ·b or q ∣ ρ′·b. Per branch of these choices, r − 1 relations C_k (centred
residues of Y_k·rows mod q with Σ|C_kj| < q, hence C_k·b = 0 over ℤ) and an X with X·C ≡ e_j − e_(r−1) (mod P), P ≥ 3, force b
constant, so |E| ∈ {0, v} ≠ k. If every branch closes, no SDS exists.
