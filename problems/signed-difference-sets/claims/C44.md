# C44 Line tomography when n = p²

Let p be prime, D an SDS (v, k, λ) on G with k − λ = p², s = ΣD = p·q, and φ : G → ZMod p × ZMod p onto (v = c·p²). Every line
contraction Y (fibres c·p) has autocorrelation p²·δ + λcp, so it is constant mod p (p is totally ramified in ℚ(ζ_p):
`congr_of_autocorr_sq`); with sum p·q and square sum p·q² + p(p − 1) its entries are ≡ q ± 1 mod p, and when c·p < q + p − 1 only
q + 1 fits. The line identity at g = 0 (C41) then needs p ∣ q + 1. So if c·p < q + p − 1 and p ∤ q + 1, no SDS exists.
