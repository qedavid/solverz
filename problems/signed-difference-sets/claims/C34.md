# C34 The divided contraction below a Ma quotient

Let D be an SDS (v, k, λ) on G, H = ZMod(r p) × K a C21 quotient (p an odd prime, r a power of p, p^i h = −h on K,
p^e ∣ n = k − λ, 1 ≤ b ≤ e/2) with fibres of size c, and W the coset sums along G → ZMod r × K (fibres p c). Then
Z = W/p is an integer vector on ZMod r × K with |Z| ≤ c, ΣZ² = Q (p²Q = k + λ(pc − 1)), autocorrelation t (pt = λc) at
every shift ≠ 0, ΣZ = ±s' (p s' = s, s² = k + λ(v − 1)) and Σ|Z| ≤ k' and Σ|Z| ≡ k' (mod 2), with k' ≡ k (mod 2), k < p(k' + 2). If no such
vector exists, no SDS exists.
